## 互換性

- `admin_get_occurrence_editor(bigint)` は変更せず、従来の group/classes の完全な形を維持します。
- `admin_get_occurrence_editor(bigint, boolean)` を追加します。既定引数を設けず、明示的な引数名でのみ選択します。
- API GET は従来URLの応答を維持します。新画面のみ `?includeParticipationNotes=1` を付けます。
- `admin_save_occurrence(uuid,jsonb)` の引数、戻り値、既存の所有者/EXECUTE権限を維持します。
- 旧入力に参加案内キーを足さないため、過去の保存要求は同じキー・同じ本文で再確認できます。過去の内部記録を更新しません。
- 旧形式で新しい保存を行う場合は、参加案内を更新しません。旧形式の競合検知は従来項目に対して行い、最新の参加案内を保持します。
- 新形式は参加案内を含むスナップショットを必須とし、同項目の並行変更も PT409 で拒否します。
- 空欄はアプリでNULLに正規化します。非空文字列と編集開始時スナップショットの空白・改行は保持します。
- 参加案内は公開情報です。公開詳細に表示され、既存のテーブルSELECT権限とRLSに従います。個人情報・内部メモを記入しないでください。
